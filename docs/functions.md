 # Functions
 Данный документ содержит описание всех функций, реализованных в файлах репозитория:
## [square.py](../square.py):
данный файл содержит функции, которые вычисляют *площадь и периметр квадрата.*
### Функция area:
    принимает число a типа float.
    возвращает квадрат числа a.

    прмиер вызова:
    S = area(8) // вернет 64.
### Функция perimeter:
    принимает число a типа float.
    возвращает произведение 4 и a.

    пример вызова:
    P = perimeter(8) // вернет 32.
### Код:
```python

def area(a: float):
    return a * a


def perimeter(a: float):
    return 4 * a
```

## [rectangle.py](../rectangle.py):
данный файл содержит функции, которые вычисляют *площадь и периметр прямоугольника.*
### Функция area:
    принимает два числа типа float: a и b.
    возвращает их произведение.

    пример вызова:
    S = area(3,4) // функция вернет 12
### Функция perimeter:
    принимает два числа типа float: a и b.
    возвращает удвоенное произведение их суммы.

    пример вызова:
    P = perimeter(5,4) // функция вернет 18
### Код:
```python
def area(a: float,b: float):
    return a*b

def perimeter(a: float,b: float):
    return (a+b)*2
```

## [circle.py](../circle.py):
данный файл содержит функции, которые вычисляют *площадь круга и длину окружности.*
### Функция area:
    Принимает число r типа float.
    возвращает произведение квадрата r и числа пи из библиотеки math.

    пример вызова:
    S = area(5) // вернет 78.53981633974483
### Функция perimeter:
    Принимает число r типа float.
    возвращает удвоенное произведение r и числа пи из библиотеки math.

    пример вызова:
    P = perimeter(5) // вернет 31.41592653589793
### Код:
```python
import math


def area(r: float):
    return math.pi * r * r


def perimeter(r: float):
    return 2 * math.pi * r

```
