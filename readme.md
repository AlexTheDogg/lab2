# Лабораторная работа 2 по ИСРПО.
Данный репозиторий представляет собой набор функций для вычисления площади и периметра некоторых геометрических фигур, а также [*документацию*](docs) по проекту, В которой содержатся:
- [*история коммитов*](docs/commits_history.md)
- [*описание функций*](docs/functions.md)
- [*общее описание выполнения лабораторной работы*](docs/solution_description.md)
## Структура репозитория:
```
lab2/
├── docs/ # каталог с документацией проекта
│   ├── commits_history.md
│   ├── solution_description.md
│   └── functions.md
├── square.py
├── circle.py
├── rectangle.py
└── readme.md # файл с описанием проекта
```
## Установка и использование
1. **Склонируйте репозиторий в удобную папку**
```bash
git clone https://github.com/AlexTheDogg/lab2.git
```
2. **Перейдите в корневую папку репозитория**
3. **Запустите нужный файл**
```bash
python3 rectangle.py
python3 circle.py
python3 square.py
```
